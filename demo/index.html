Security Architecture
Internet (Untrusted)
Public internet facing zone. All traffic filtered by ISP ACLs.
Firewall DMZ
HQ-FWL + B-FWL (Cisco ASA). Stateful inspection, NAT, ACLs on HTTP/FTP/SMTP/SSH/DNS/DHCP.
Internal Networks
VLANs segmented per department. 802.1Q trunking between switches and routers.
Wireless Zone
WLC at 10.10.0.15 manages APs. CAPWAP traffic allowed through ACLs.

About

Designed by Biniyam Ademasu Afework using Cisco Packet Tracer. This enterprise campus network implements defense-in-depth security with dual ASA firewalls, OSPF dynamic routing, VLAN segmentation, and site-to-site IPSec VPN.
