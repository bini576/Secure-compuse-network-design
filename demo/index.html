Security Zones

Internet (Untrusted)

Public internet facing zone. All traffic filtered by ISP ACLs before reaching the firewall.

Firewall / DMZ

HQ-FWL + B-FWL (Cisco ASA). Stateful inspection, NAT, ACLs on HTTP/FTP/SMTP/SSH/DNS/DHCP.

Internal Network

VLANs segmented per department. 802.1Q trunking between switches and core routers.

Wireless Zone

WLC at 10.10.0.15 manages lightweight APs via CAPWAP (UDP 5246/5247).
